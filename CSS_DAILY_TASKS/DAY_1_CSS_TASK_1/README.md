# College Application Form

This project is a simple **College Application Form** created using **HTML and CSS**. The form is designed to collect basic student information and course details in a structured and user-friendly format.

## 📌 Project Description

The College Application Form contains fields for entering the student's first name, last name, email address, phone number, gender, known languages, preferred course, date, and time. It also includes a checkbox-style confirmation option and Register and Reset buttons.

The form is styled using CSS properties such as **borders, margins, padding, background colors, outlines, box sizing, and text alignment**. Different sections of the form are highlighted using colors to make the design clear and easy to understand.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Student first name and last name fields
* Email input field
* Phone number field
* Gender selection
* Known language selection
* Course selection dropdown
* Date and time selection
* Details confirmation option
* Register button
* Reset button
* Basic CSS styling

## 🎯 Purpose

The main purpose of this project is to practice creating HTML forms and applying CSS styling. It helps in understanding different HTML form elements such as `input`, `select`, `option`, `label`, and `button`, along with CSS concepts like margins, padding, borders, outlines, and backgrounds.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the HTML file in any web browser.
3. Fill in the required details.
4. Click the **Register** button to submit the form.
